# Co kdybych?

Czech web app: "What if I had invested X CZK every month since <date>?" The user enters a monthly
amount (CZK, optional one-off initial deposit), a start month and assets to compare (S&P 500 with
reinvested dividends, gold, Bitcoin, savings account, cash). The app shows what it would be worth
today, nominally or in today's crowns (inflation-adjusted). Audience: Czech Gen Z, mostly arriving
from Instagram (@filipvondy) on mobile. Portfolio project; the owner is learning, so briefly explain
the "why" behind important decisions.

## Commands

- `npm run dev` – dev server on http://localhost:3000
- `npm test` – Vitest, single run (`npm run test:watch` to watch)
- `npm run lint`, `npm run typecheck`
- `npm run build` – production build (also type-checks)
- `npm run data` – re-download market data (added in step 2; needs `.env.local`, see `.env.example`)

## Architecture

- Next.js 16 App Router (`cacheComponents` enabled), TypeScript, Tailwind CSS 4, Recharts,
  html-to-image. Next 16 differs from older versions: read `node_modules/next/dist/docs/` before
  using an API you are not sure about.
- One static page; everything is computed in the browser. No database, no auth, no API calls at
  runtime. Market data are JSON files in `src/data/`, generated by `scripts/fetch-data.ts`.
- `src/lib/calc/` – pure calculation functions (simulation, XIRR, max drawdown, inflation
  adjustment, lesson sentence). No React, no I/O. Covered by Vitest, including hand-verifiable cases.
- `src/lib/format.ts` – Czech formatting via `Intl` (`cs-CZ`). Output contains NBSP (U+00A0).
- `src/brand.config.ts` – single source of truth for brand colors, font, handle and disclaimer.
- Inputs are mirrored in URL search params so a result can be shared by link.
- The project path must not contain `?` – Turbopack truncates paths at it and the build fails.

## Data rules

- Never invent or "fill in" data. If a source fails, the script fails loudly and names the source.
- Do not bypass bot protection of data sources (Yahoo, Stooq, …). Use official/open sources.
- USD prices → CZK with the ČNB rate of the same month (last business day). Final value uses the
  rate of the end month.
- End month = last month for which all series have data. Values are "as of" the end of that month.
- An asset without data for the chosen start month is shown as unavailable and not computed.
- No fees, no taxes (stated in the disclaimer).

## Conventions

- UI copy in Czech: friendly, informal (tykání), short punchy sentences. Code, identifiers and
  comments in English.
- Czech number format: `1 234 567 Kč`, `12,3 %`. Always use the helpers in `src/lib/format.ts`.
- Mobile-first: design for ~375px width first, then scale up.
- Disclaimer (footer and share image), verbatim: „Obsah je pouze informativní, nejde o finanční
  poradenství. Minulé výnosy nezaručují budoucí. Výpočet nezahrnuje poplatky ani daně."

## Workflow

The app is built in steps. After each step: `npm test`, `npm run lint`, `npm run build`, check the
dev server, summarize the change briefly, then make a git commit.
