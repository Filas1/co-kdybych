# Co kdybych?

Czech web app: "What if I had invested X CZK every month since <date>?" The user enters a monthly
amount (CZK, optional one-off initial deposit), a start month and assets to compare (S&P 500 with
reinvested dividends, gold, Bitcoin, savings account, cash). The app shows what it would be worth
today, nominally or in today's crowns (inflation-adjusted). Audience: Czech Gen Z, mostly arriving
from Instagram on mobile. Portfolio project; the owner is learning, so briefly explain the "why"
behind important decisions.

The site is intentionally NOT tied to the owner's personal social profile: no handle anywhere in
the UI or on the share image (the image shows the site URL instead).

Production: https://www.cokdybych.cz (Vercel, deploys automatically on every push to `main`;
repo github.com/Filas1/co-kdybych). `cokdybych.cz` and `co-kdybych.vercel.app` redirect to www.
The canonical URL is set in `brand.siteUrl`; change it there if the primary domain changes.

## Commands

- `npm run dev` – dev server on http://localhost:3000
- `npm test` – Vitest, single run (`npm run test:watch` to watch)
- `npm run lint`, `npm run typecheck`
- `npm run build` – production build (also type-checks)
- `npm run data` – re-download market data into `src/data/market.json` and print check values
  (needs `.env.local`, see `.env.example`). Runs TypeScript directly on Node ≥ 22.18, no build step.

## Architecture

- Next.js 16 App Router (`cacheComponents` enabled), TypeScript, Tailwind CSS 4, Recharts,
  html-to-image. Next 16 differs from older versions: read `node_modules/next/dist/docs/` before
  using an API you are not sure about.
- One static page; everything is computed in the browser. No database, no auth, no API calls at
  runtime. Market data are JSON files in `src/data/`, generated by `scripts/fetch-data.ts`.
- `scripts/sources/` – one module per data source (ČNB FX, ČSÚ CPI, FRED Bitcoin, World Bank
  gold, Alpha Vantage SPY, ČNB ARAD savings rates); parsers are pure and tested in
  `scripts/**/*.test.ts`. `scripts/lib/assemble.ts` aligns series and refuses gaps.
  `src/lib/market-data.ts` defines the JSON shape shared by the script and the app.
- Script imports use explicit `.ts` extensions (Node type stripping requires them).
- `src/lib/calc/` – pure calculation functions (simulation, XIRR, max drawdown, inflation
  adjustment, lesson sentence). No React, no I/O. Covered by Vitest, including hand-verifiable cases.
- `src/lib/format.ts` – Czech formatting via `Intl` (`cs-CZ`). Output contains NBSP (U+00A0).
- `src/brand.config.ts` – single source of truth for brand colors, asset colors, site URL and
  disclaimer. The root layout turns `brand.colors` into `--brand-*` CSS variables; `globals.css`
  maps them to Tailwind colors (`bg-surface`, `text-accent`, …). Never hardcode hex in components.
  Font (Space Grotesk, latin-ext) is loaded in `src/app/fonts.ts`. Theme is dark-only (variant "Noc").
- Asset colors were validated for color-vision deficiency against the dark background; cash is
  neutral gray (in nominal mode it equals the "invested" line, which is dashed).
- `src/components/` – `Calculator` (client state, recomputes on every change), `InputsForm`,
  `Results` (with `ModeToggle`, `SavingsRateField`, `ChartSection`), `Footer`.
- Chart: `src/lib/chart-data.ts` (pure: series, rows, ticks, `dominantAsset`) + `ValueChart`
  (Recharts 3, `responsive` prop, animation off, custom tooltip; a fixed `width` and
  `interactive={false}` render it for the share image). When one asset's peak is ≥ 3× every other
  line (in practice Bitcoin), `ChartSection` offers hiding it from the chart only.
- `react-is` must match the installed React version (Recharts requirement).
- Performance: `ChartSection` and `ShareCard` are loaded with `next/dynamic` (`ssr: false`) and
  html-to-image with a dynamic `import()`, so Recharts (~100 kB gz) is not in the initial bundle.
- Metadata: `layout.tsx` (Open Graph, Twitter, `metadataBase` = `brand.siteUrl`),
  `opengraph-image.tsx` (real default scenario computed at build), `icon.tsx`, `apple-icon.tsx`,
  `robots.ts`, `sitemap.ts`. Image routes read fonts from `assets/fonts` via `src/lib/og-fonts.ts`
  synchronously – an async read would make them dynamic under Cache Components. All routes must
  stay static (`○` in the build output).
- Touch targets ≥ 44 px (`min-h-11`), animations behind `motion-safe:`; layout checked at 320 px.
- Shareable link: `src/lib/url-state.ts` (Czech params `mesicne`, `vklad`, `od`, `aktiva`,
  `realne`, `sazba`; forgiving parser). `Calculator` reads them once via `useSearchParams`
  (wrapped in `<Suspense>` in `page.tsx`, otherwise the static build fails) and writes changes
  back with `history.replaceState`.
- Story image: `src/lib/share-content.ts` (text, tested) + `ShareCard` (1080×1920, mounted
  off-screen only while capturing, hero number measured to fit) + `ShareBar` (html-to-image
  `toBlob` twice – Safari drops fonts on the first pass – with the font CSS cached; preview in a
  native `<dialog>`, then Web Share with the file, or PNG download). Generation takes ~0.1 s in a
  visible tab; hidden/background tabs throttle timers and make it look slow. `src/lib/inputs.ts` holds
  defaults, limits and validation; `src/lib/market.ts` loads the bundled JSON.
- Inputs are mirrored in URL search params so a result can be shared by link.
- The project path must not contain `?` – Turbopack truncates paths at it and the build fails.

## Data rules

- Never invent or "fill in" data. If a source fails, the script fails loudly and names the source.
- Do not bypass bot protection of data sources (Yahoo, Stooq, …). Use official/open sources.
- USD prices → CZK with the ČNB rate of the same month (last business day). Final value uses the
  rate of the end month.
- End month = last month for which all series have data. Values are "as of" the end of that month.
- An asset without data for the chosen start month is shown as unavailable and not computed.
- No fees, no taxes (stated in the disclaimer).

## Conventions

- UI copy in Czech: friendly, informal (tykání), short punchy sentences. Code, identifiers and
  comments in English.
- Copy must not assume the reader's gender: no "měl/investoval/byl" about the reader. Rephrase
  ("Kolik by dnes měly tvoje peníze", "z X máš Y") or talk about the asset ("Bitcoin spadl").
- Month names after "od/do" need the genitive: use `formatMonthGenitive` ("od prosince 2014").
- Czech number format: `1 234 567 Kč`, `12,3 %`. Always use the helpers in `src/lib/format.ts`.
- Mobile-first: design for ~375px width first, then scale up.
- Disclaimer (footer and share image), verbatim: „Obsah je pouze informativní, nejde o finanční
  poradenství. Minulé výnosy nezaručují budoucí. Výpočet nezahrnuje poplatky ani daně."

## Workflow

The app is built in steps. After each step: `npm test`, `npm run lint`, `npm run build`, check the
dev server, summarize the change briefly, then make a git commit.
